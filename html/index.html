Module 1: HTML Basics

=> what is html

HTML ka full form hai: Hyper Text Markup Language


=>HTML Boilerplate

Boilerplate ka matlab hota hai basic template ya starting code. 


<!DOCTYPE html>
<html lang="en">

<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>My First Website</title>
</head>

<body>

    <h1>Hello Manas!</h1>

</body>

</html>

=>HTML Structure

1. <!DOCTYPE html>

Definition: Ye browser ko batata hai ki ye document HTML5 me likha gaya hai.

2. <html>

Definition: <html> tag HTML document ka main (root) tag hota hai. Website ka pura HTML code isi tag ke andar likha jata hai.

3. <head>

Definition: <head> tag ke andar webpage ki information rakhi jati hai, jaise title, meta tags, CSS files aur JavaScript files. Iske andar ka content webpage par direct dikhai nahi deta.

4. <body>

Definition: <body> tag ke andar webpage ka sara visible content hota hai, jaise headings, paragraphs, images, links, tables aur forms. Jo bhi user website par dekhta hai, wo sab <body> ke andar likha jata hai.


=>Headings

Definition: HTML me headings kisi webpage ka title ya important text dikhane ke liye use hoti hain. HTML me total 6 heading tags hote hain, jo <h1> se <h6> tak hote hain.

1. <h1>

Definition: Ye sabse badi aur sabse important heading hoti hai. Ek webpage me normally sirf ek <h1> use karna best practice mana jata hai.

2. <h2>

Definition: Ye second level ki heading hoti hai. Iska use main heading ke andar alag sections banane ke liye kiya jata hai.

3. <h3>

Definition: Ye third level ki heading hoti hai. Iska use sub-section banane ke liye kiya jata hai.

4. <h4>

Definition: Ye fourth level ki heading hoti hai. Iska size <h3> se chhota hota hai.

5. <h5>

Definition: Ye fifth level ki heading hoti hai. Iska use kam important headings ke liye kiya jata hai.

6. <h6>

Definition: Ye sabse chhoti heading hoti hai. Iska use sabse kam important heading ke liye kiya jata hai.

Example


<h1>Heading 1</h1>
<h2>Heading 2</h2>
<h3>Heading 3</h3>
<h4>Heading 4</h4>
<h5>Heading 5</h5>
<h6>Heading 6</h6>

Output

Heading 1
Heading 2
Heading 3
Heading 4
Heading 5
Heading 6

Important Points

  • HTML me total 6 heading tags hote hain.
  • <h1> sabse badi heading hoti hai.
  • <h6> sabse chhoti heading hoti hai.
  • Heading sirf size ke liye nahi, content ki importance batane ke liye bhi use hoti hai.
  • SEO ke liye <h1> bahut important hoti hai.

=>Paragraph

Definition: HTML me paragraph likhne ke liye <p> tag ka use kiya jata hai. Is tag ke andar hum normal text ya information likhte hain.

1. <p>

Definition: <p> tag webpage par ek paragraph create karta hai. Browser iske upar aur niche automatically thodi space (margin) de deta hai, jisse content padhne me aasaan lagta hai.

Example


<p>Hello, My name is Manas.</p>

<p>I am learning HTML.</p>

Output

Hello, My name is Manas.

I am learning HTML.

Important Points

  • <p> tag normal text likhne ke liye use hota hai.
  • Har paragraph apni nayi line se start hota hai.
  • Browser paragraph ke upar aur niche automatically space add karta hai.
  • Paragraph ke andar text, links, images aur kuch inline elements bhi use kiye ja sakte hain.

Note

Agar tum paragraph ke andar multiple spaces ya Enter dabaoge, to browser unhe ignore kar dega. Browser extra spaces aur extra line breaks ko ek hi space ki tarah show karta hai.

Example


<p>
Hello


I am


Learning HTML
</p>

Browser Output

Hello I am Learning HTML

Agar tum line break dikhana chahte ho, to <br> tag ka use karo.

=>Comments

Definition: HTML me comments ka use code ke baare me notes ya explanation likhne ke liye kiya jata hai. Comments browser me dikhai nahi dete, sirf developer ko dikhte hain.

1. HTML Comment Syntax

Definition: HTML comment <!-- se start hota hai aur --> se end hota hai.

Syntax


<!-- This is a comment -->

Example


<h1>Welcome</h1>

<!-- Ye heading website ka main title hai -->

<p>I am learning HTML.</p>

Output

Welcome

I am learning HTML.

Note: Comment browser me show nahi hoga.

Comments ka Use

  • Code ko explain karne ke liye.
  • Important notes likhne ke liye.
  • Kisi code ko temporary disable (hide) karne ke liye.
  • Code ko padhne aur samajhne me aasani hoti hai.

Example (Code Hide Karna)


<h1>Hello</h1>

<!--
<p>Ye paragraph abhi browser me show nahi hoga.</p>
-->
Browser Output

Hello

Sirf <h1> dikhai dega. Comment ke andar wala code browser ignore kar dega.

Important Points

  • Comment browser me dikhai nahi deta.
  • Comment sirf developer ke liye hota hai.
  • HTML comment <!-- se start aur --> se end hota hai.
  • Comments website ke output ko affect nahi karte.
